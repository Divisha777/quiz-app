# Quiz Application with Score Tracking

A simple console quiz program written in C++.

## Features
- Asks the player for their name
- Shows 5 multiple-choice questions, one at a time
- Checks that the answer entered is a valid option (1 to 4)
- Calculates the final score and percentage
- Saves the player's name and score to `scores.txt`

## Concepts used
- Classes and objects (`Question` class with a constructor)
- Vectors (list of questions and options)
- Strings
- File handling (`ofstream`)
- Functions
- Exception handling (`try`, `catch`, `throw`)

## How to run
Compile:

    g++ quiz.cpp -o quiz

Run:

    ./quiz
